## 📌 About This Repository

This repository documents my learning and project work throughout the internship.

The internship follows a task-based workflow where each assignment is supported by:

- Incoming task assignments
- Task completion checkpoints
- Multiple quality checks
- Project-specific reviews
- Client-oriented presentations

The work progresses from **data analysis and SQL** toward **data cleaning, feature engineering, predictive modelling, MLOps, and application development**.

The first week focused on onboarding, understanding the internship workflow, completing the first data task, and presenting analytical findings.

### Main activities

- Internship onboarding and introduction

- Completing the first assigned data task

- Learning Scrum fundamentals
- Completing Scrum knowledge checks
- Completing Week 1 successfully

### 📊 Featured Analysis: Campaign Performance Analysis

One of the major Week 1 deliverables was a **Campaign Performance Analysis for Nova Mart**.

The analysis covered:

- City-wise store distribution
- Sankranti campaign category performance
- Price vs. quantity correlation
- Quantity distribution before promotions
- Incremental Sold Units (ISU%) by city
- Incremental units vs. incremental revenue by promotion type
- Bengaluru revenue before and after promotions by category

### Tools used

- Python
- Pandas
- Matplotlib
- Seaborn

The project focused not only on performing analysis but also on **communicating the results as business insights for a client**.

This workflow has helped me understand how different stages of a data science project connect with each other, rather than treating modelling as an isolated step.
